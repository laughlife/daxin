feat: 把首屏动态背景提取为动画 WebP，替换原来的纯 CSS 动态背景

需求：banner 配置的就是首屏背景；把首屏的动态背景提取成动图，上传配置，
用它替换现在 CSS 实现的动态背景。

## 一、提取（新增 tool）

首屏背景由两层 CSS 构成，都是动态的：
- `::before` 呼吸光晕（hero-atmosphere 12s alternate）
- `::after` 滚动网格（hero-grid 18s linear infinite）
- 加两个漂浮光斑 .home-hero__orb（hero-float **14s** infinite）

新增 `tools/capture-hero-animation-frames.mjs`：
- 探测到光斑周期是 14s，**采满一个完整周期**（84 帧 / 6fps），
  否则循环点相位不一致、肉眼能看到跳变；
- 采样时隐藏页头（`position:sticky` 会盖住首屏，否则导出图里带 logo 与导航）、
  公告条、以及 Nuxt DevTools 悬浮球（开发模式产物，不能烘进素材）；
- 用 `visibility` 而非 `display:none`，避免改变布局导致首屏位移。

新增 `tools/build-hero-animation.mjs`：Pillow 合成动画 WebP，
末尾若干帧向起始帧**交叉淡化**抹平接缝，并在超出体积上限时自动降宽降质重试。

结果：**84 帧 → 74 帧有效循环、1600x521、仅 144KB**（无损 PNG 帧序列约 40MB）。

另出静帧 poster（1600x521，35KB），给不支持动画 WebP 的浏览器回退。

## 二、配置（迁移 011）

新增两个键并置于 home 组最前（背景是整块首屏的底，按页面顺序应最先出现）：
- `home_hero_background` → 动画 WebP
- `home_hero_background_poster` → 静态首帧

## 三、替换 CSS 动态背景

`HomeHero` 在配置了背景图时：
- 给根元素加 `home-hero--image-bg`，内联 `background-image` 指向动图，
  并附上 poster 作为第二层回退；
- **关闭 ::before / ::after**（这两层就是原来的 CSS 动态背景本体），
  不关会与图里的图案重影；
- 不再渲染 `.home-hero__decor` 光斑元素；
- 未配置时完全保持原样走 CSS 背景，任何情况下首屏都有底、不会开天窗。

## 四、顺带处理

首页那个 Banner 区块展示的是同一张背景图案，紧挨首屏、内容重复，
已清空 `home_banner_image` 配置（区块不渲染）。如需保留可在「图片管理」重新上传。

## 五、过程中修掉的两个自己的问题

1. **上传工具读不出 WebP 尺寸**：`readImageSize` 只处理 PNG/JPEG，
   动画 WebP 的宽高被记成 NULL。已补 RIFF/WEBP 解析
   （VP8X 画布尺寸为「值减一」的 24 位小端，另兼容 VP8 / VP8L），重传后尺寸正确。
2. **配置脚本取错媒体**：动图与 poster 同属 `hero/` 前缀，
   只按前缀取会拿到 id 更大的那张，导致两个键都指向了 poster。
   已改为按扩展名区分（`.webp` / `.jpg`）。
