## 一、项目概况

大信法务团队官网从零重构，与旧 PHP CMS 完全隔离。最终架构为 Nuxt 4（前端 SSR/SSG）+ Laravel 13 + Filament 5（后台）+ MySQL 8，分四个里程碑交付。当前完成 M1 前端演示阶段，全部使用本地 Mock 数据，未连接任何后端、数据库或旧系统。

- **SEO**：title / description / og 标签、首页 LegalService JSON-LD。

## 七、已知问题与注意事项

### 技术侧

1. **TypeScript 锁定 5.9.3**：TS 7.0 与当前 vue-tsc 3.3.11 不兼容，升级需等待 vue-tsc 适配。
2. **Node 24 DEP0155 警告**：`@vue/shared` 的 exports 尾斜杠映射在 Node 24 产生弃用提示，不影响构建，需等待 Vue 上游修复。
3. **esbuild allowScripts 提示**：npm 11 提示 esbuild 安装脚本未列入 allowScripts，不影响功能。
4. **本地 10 个提交未推送**：`main` 分支比 `origin/main` 超前 10 个提交，需手动 `git push`。
5. **AGENTS.md.bak**：根目录存在一个空的未跟踪备份文件，可安全删除。
6. **浏览器交互未自动化测试**：弹窗焦点还原、移动端抽屉、搜索分页等已按规范实现，但本环境无 Playwright，正式验收前建议在真实浏览器（含 390px 窄屏）人工复核。

### 业务侧（待甲方提供）

2. 两个微信咨询号的正式二维码图片。
