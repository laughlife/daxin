## 新增表建议

- `cases`：案件号、法院、立案日期、原告、案件状态及更新时间。法院与规范化案件号共同去重；缺少法院时标记待核实，不仅按案件号合并。
- `brands`：品牌名称、别名、标识图片、介绍。
- `law_firms`：律所名称、别名、介绍、官网。
- `ip_types`：商标、版权、专利等类型。
- `case_brands`、`case_law_firms`、`case_ip_types`：关联表，关联组合加唯一约束。
- `case_sources`：关联旧文章并记录出处与人工核验状态。

品牌库统计从结构化关联查询得出，不保存重复的计数字段。总品牌数按品牌 ID 去重；按侵权类型统计时也按品牌 ID 去重。品牌可能同时涉及多个类型，所以分类数量之和不一定等于总品牌数。律所详情展示关联案件、品牌与类型；首页近期案件按 `filed_at` 筛选，文章更新列表则按 `cn_list.dateline/lastdate`。

若仍使用 PHPOK 后台，可通过其扩展字段机制协调修改 `cn_fields` 与 `cn_list_5`，加入简单字段。但正文含多个案件号和多个关联实体时，独立案件表更适合筛选、去重和统计。此次未执行数据库 DDL、数据迁移或新站接口改动。
