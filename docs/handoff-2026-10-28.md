## 一、待办三项

### ① 品牌目录：重写主查询，去掉 `case_brands` 关联

- **文件**：`web/server/utils/public/case-queries.ts`，函数 `findBrandDirectoryPage`（约 524–585 行）
- **现状**：`SELECT` 已补 `cover_url / ip_category / brand_owner`，但 `FROM` 仍在
  `LEFT JOIN case_brands cb` 与 `LEFT JOIN ( ... ROW_NUMBER() ... ) latest`，
  而采集已不再写 `case_brands` / `case_law_firms`，导致：
  - `plaintiff` / `lawFirm` 空
  - `case_count` 恒为 0（排序也因此失效）
  - `case_types` 空 → 分类筛选统计 `trademark/patent/copyright` 全是 0
- **目标**：改为与 `publishedEntityCaseCountSql` 一致的文本匹配子查询
  （英文主干 `*_latin` 双向包含或前 6 位相同；中文名称去空格双向包含；律所含简称）
- **坑**：`publishedEntityCaseCountSql` 内部用别名 `e`，品牌目录查询的别名是 `b`，
  直接拼接会 `Unknown column 'e.xxx'`。二选一：
  - 给该函数加别名参数（推荐）
  - 或 `.replace(/\be\./g, 'b.')`
