## 后续接入数据

`cn_list` 提供标题、项目、发布日期等元数据，各 `cn_list_N` 提供正文及摘要。新版 `app/data/legacy/articles.json` 保存文章元数据，`app/repositories/articleContent.ts` 按来源文章 ID 读取 `{ html, images }`。后续接口应返回同样的正文结构，并在服务端清洗 HTML 和规范图片地址；数据库凭据只放在服务端。当前清洗发生在导入阶段，前端不能直接渲染未经清洗的接口 HTML。

本次临时 MCP 导出文件保存在忽略目录 `tmp/legacy-preview`；导入脚本 `tools/import-legacy-content/expand_articles.py` 负责归类，`import_legacy.py` 负责清洗与复制引用的图片。脚本不读取数据库密码。
