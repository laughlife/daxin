# 后台左侧导航与管理界面精简设计

## 目标

把大信法务后台统一为左侧菜单导航，减少面向业务人员无用的说明、状态字段和内部标识，使常用编辑内容更直接、更易读。

## 导航与页面框架

- 在共用 `admin` 布局内提供桌面固定左侧导航，支持分组和展开/收起的子菜单；窄屏切换为抽屉菜单。
- 导航包含后台首页、站点设置、首页业务内容、文章、案件、品牌、律所和用户管理，并按现有角色权限控制访问状态。
- 从共用布局移除右上方“返回后台首页”和“返回官网首页”。后台首页继续从侧栏入口访问。
- 后台各管理页移除只解释用途的标题副标题、配置分组描述和字段说明；必要的校验错误、只读提示、上传反馈和保存结果保留。

## 表单与编辑

- 管理表单优先采用左侧字段名、右侧内容的横向布局；窄屏下自动切换为上下排列。
- 所有后台多行文本编辑框随内容自动增高，隐藏文本框内部滚动条。
- 配置表单不显示状态控件。文章、案件、用户、实体及业务模块的列表与表单不显示状态筛选、状态列或状态编辑控件。
- 隐藏状态字段时，服务端 API、数据库字段和现有记录的状态值保持不变；编辑其他字段时继续提交记录原状态，避免意外修改。
- 新文章和新案件默认保存为草稿；用独立的“发布文章”/“发布案例”操作发布，不使用状态下拉框。普通编辑保持原有状态。
- 新建账号默认启用；账号现有状态只在内部保留，不显示状态列或停用控件。品牌、律所和首页业务配置的状态值也在更新时原样保留，不提供归档或状态切换操作。
- 文章预览使用当前未保存的标题、摘要、图片和正文，按公开文章样式呈现。
- 业务配置界面只保留首页实际展示所需的板块标题、板块说明、图标、子项标题与说明。排序数字、状态、Slug、详情链接、显示详情链接开关及其说明不向业务人员展示；既有服务数据和 API 结构继续兼容。

## 验收标准

- 任一后台管理页都能通过左侧菜单切换；当前路径高亮，父菜单可展开，移动端可以打开和关闭抽屉。
- 共用布局不再显示两个右上返回入口；后台首页内容不重复展示用途说明卡片。
- 所有管理页的用途型副标题和配置字段解释说明已移除；站点设置字段名与编辑内容横向排列，状态控件不显示。
- 文章、案件、用户及实体管理不展示状态筛选、列表状态列或表单状态字段；编辑保存不会改变原状态值。
- 新建文章默认存草稿，可预览当前编辑内容，也可显式发布。
- 新建案件默认存草稿并可显式发布；编辑既有文章/案件时，普通保存不改变其原发布状态。
- 新建账号默认启用；已有账号状态不能通过本后台编辑页面更改。
- 团队业务配置界面不再出现排序、状态、Slug、详情链接或显示详情链接设置，仍能维护公开页面所需文本与图标。
- 全部大文本编辑器没有内部滚动条，内容变长时输入框自动增高。
- 数据 API 不因后台展示调整而删除字段、记录或关系。

## 暂定边界

- 这次不删除任何数据库字段、接口字段、已有状态值或业务配置记录；状态仅从管理界面隐藏，并在普通编辑更新时保留。发布操作仍以清晰的发布动作表达，不显示状态下拉框。
- 预览不保存草稿、不改变发布状态，也不离开当前编辑页。
- 核验队列的“待核验/确认/驳回”属于队列处理流程，继续保留队列筛选和确认/驳回操作；此次隐藏的是文章、案件、账号、实体和业务内容的普通状态字段。
