# 首页轮播与全站配色配置设计

## 目标

让首页“普法干货”书本轮播支持悬停暂停、指示点切换，并让管理员可以在站点设置中选择整站配色或输入自定义 HEX 主色。第三个国际物流主题尚无领取内容时保持现状；管理员填入领取说明后，公开页显示领取文案、二维码和“添加领取”。

## 现状

- `HomeLegalGuides.vue` 每 5 秒自动切换，但没有暂停控制；底部指示点是不可交互的 `span`。
- `site_settings.home_legal_guides` 已保存三个固定主题及各自主题色，公开设置接口将已发布配置提供给前端。
- 全站核心配色由 `tokens.css` 的 CSS 变量控制，站点设置页面按 `site`、`home`、`about` 分组编辑数据库配置。

## 设计

### 首页书本轮播

- 自动播放间隔维持 5 秒。
- 鼠标/指针进入轮播卡片或底部指示点区域时暂停；离开整个轮播区域后恢复计时。组件卸载时清理计时器。
- 指示点改成按钮。悬停或聚焦可预览对应主题，点击可固定切换；按钮提供主题名称和当前页语义，支持键盘操作。
- 第三个“国际物流”主题默认关联 `qr-tro-consult`。其领取说明为空时不显示领取区；说明有内容且所选二维码存在时，显示对勾、领取说明、二维码与“添加领取”。后台可从已有四类二维码中选择该页使用的二维码；空值时不显示二维码区域。
- 保留 TRO、劳动法主题各自的紫色/橙色主题色，不随全站配色覆盖。

### 后台站点配色

- 在“站点信息”增加“全站配色”设置，保存到现有 `site_settings` 的 `site` 分组，不另建表。
- 内置选项：
  - 大信经典红：主色 `#B91C1C`，点缀色 `#C9A45C`
  - 律政藏蓝：主色 `#244A73`，点缀色 `#C9A45C`
  - 雅致墨绿：主色 `#28675A`，点缀色 `#C9A45C`
  - 商务紫：主色 `#642A86`，点缀色 `#D7B5E8`
- 提供自定义主色 HEX 输入。仅接受 `#RRGGBB`；无效值不允许保存。颜色深浅由 CSS `color-mix()` 从主色派生，正文、背景、状态色等中性色保持原令牌。
- 公开页面从现有 `/api/public/settings` 获取配置，在根公开布局映射 CSS 令牌；SSR 首屏和后续导航使用相同值。后台管理页面仍使用默认后台主题。
- 缺少配置或配置值不合法时回退大信经典红，避免影响渲染。

## 数据与兼容

- 增加 `site_theme` JSON 设置项，结构为 `{ preset: 'classic-red' | 'legal-navy' | 'elegant-green' | 'business-purple' | 'custom', primary: '#RRGGBB' }`。
- 预设切换时 `preset` 与 `primary` 一起保存；自定义颜色选择时 `preset='custom'` 并保存主色。
- 更新 `home_legal_guides` 的标准化逻辑，使国际物流主题允许使用四类二维码配置键；旧配置缺字段时使用默认值，TRO 和劳动法历史值保持不变。
- 新设置由幂等 SQL migration 初始化；管理员保存仍沿用现有 settings API 和权限。

## 错误处理与安全

- 主题颜色仅接受六位 HEX，前端和共享标准化函数都校验；非法数据库值回退默认主题。
- 不接受任意 CSS 片段或 URL；主题应用只设置受控 CSS 自定义属性。
- 若二维码未配置或图片地址为空，领取区不渲染二维码，避免破图；“添加领取”只在领取说明和有效二维码都存在时显示。

## 验收标准

1. 轮播自动切换正常；悬停卡片/指示点暂停，离开后恢复。
2. 悬停、点击或键盘聚焦指示点能切到对应主题，屏幕阅读器可识别按钮名称和当前页。
3. 第三个主题无领取说明时不显示二维码；填写说明并选择可用二维码后显示领取说明、二维码、“添加领取”。
4. 站点设置可选四套预设或输入有效自定义 HEX；非法 HEX 被拒绝，保存后公开页面全局主色更新。
5. 无配置、历史配置及无效配置都回退默认红色主题；TRO / 劳动法卡片主题色保持独立。

## 不在本次范围

- 不修改书本轮播的文章、插画、正文文案和 5 秒间隔。
- 不新增二维码资源或数据库表；只引用现有四类二维码配置。
- 不重做后台整体布局或为后台管理界面套用公开页面的动态主题。
