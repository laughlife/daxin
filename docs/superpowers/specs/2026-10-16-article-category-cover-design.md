## 后台分类与封面上传

- 后台分类选项不再从当前分页文章推导。增加有 `article:read` 权限保护的活动分类读取接口，返回活动分类的 `id、slug、name`；新建和编辑共用这份完整分类字典。
- 文章编辑表单增加封面图片选择和预览。沿用 `useOssUpload` 的现有流程：申请上传凭证、浏览器直传 OSS、登记 `media_assets`，用途为 `article`。上传校验沿用现有图片格式和 20 MB 限制。
- 新建/编辑 API 接受可空的 `coverMediaId`，验证媒体记录存在、未软删除且用途为文章图片后，将 ID 写入已存在的 `articles.cover_media_id`。文章详情 API 返回 `coverMediaId` 和预览 URL；数据库无需新增字段或迁移。
- 保存时将 `coverMediaId` 与分类、正文等文章字段一起提交。上传完成但用户取消编辑时允许产生未关联媒体记录，沿用现有媒体资源生命周期，不在本任务中自动删除 OSS 对象。
- 公开文章卡片使用封面缩略图。文章详情仍只展示正文内容，不在正文前再插入封面，避免和正文图片重复。公开查询现有封面联表能力继续复用。

## 当前封面存储状态

目标库当前迁移批次有 858 篇文章，`cover_media_id` 均未关联。旧库文章表 `dr_1_news.thumb` 存附件 ID，关联 `dr_attachment_data.id` 后，从 `attachment` 取得相对路径。文章 ID 1977 的附件记录为 ID 11454，路径是 `202610/d3a71f84fefdfee.png`。图片读取地址应拼为 `https://daxinfawu.com/uploadfile/{attachment}`；该样例地址已验证返回 HTTP 200、PNG、315740 字节。

## 验收标准

1. 858 篇迁移文章都落入表格定义的新栏目，文章总数、正文、发布日期与发布状态不变；按栏目计数符合上方汇总：TRO侵权预警 718、TRO成功案例 13、CPSC召回 2、货代案例 87、跨境咨询 9、科普干货 24、热点资讯 5、劳动纠纷 0。
2. 新文章分类选择能列出所有活动分类，不受当前分页影响；编辑已迁移文章时显示其当前新分类。
3. CPSC、跨境咨询列表页按新分类查到对应内容，文章点击后进入正确详情路径；历史 `/domestic/cross-border-news` 链接仍可用。
4. 新建和编辑均可上传封面，上传失败、非文章媒体、软删除媒体和无效分类均有明确错误且不写入文章；成功保存后刷新仍显示封面预览。
5. 公开卡片显示封面；详情页不重复插入封面；没有封面的文章继续以正文首图或现有占位策略展示。
6. 运行文章分类、迁移重分类、文章管理 API、OSS 上传控件及公开列表相关测试，并构建 Nuxt 项目。
